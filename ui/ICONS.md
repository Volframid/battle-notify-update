# Game icon assets

Bundled subset of TeraDpsMeterData game icons, mapped using Asura client icon metadata. Source collection: https://github.com/neowutran/TeraDpsMeterData . See ICON-LICENSE.txt for the collection license. TERA game artwork belongs to its respective owners.

Additional Asura Lotus and brooch textures were copied from the game client to match the native notification icons. No game package modification is required.

Assets are bundled locally; no running meter, external service, or download is required. Unavailable/custom icons use a neutral marker while retaining the notification text.
